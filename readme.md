## Run Locally

**Prerequisites:** [Bun](https://bun.sh/) or Node.js with npm.

```bash
git clone https://github.com/nohith/nohith.git
cd nohith
bun install
bun run dev
```

The development server will print the local URL in your terminal.

### Useful Commands

| Command | Purpose |
|---|---|
| `bun run dev` | Start the development server |
| `bun run build` | Build the production app |
| `bun run preview` | Preview the production build |
| `bun run lint` | Run ESLint |
| `bun run test` | Run the test suite |

If you use npm, run `npm install`, then use the equivalent `npm run <script>` commands.
